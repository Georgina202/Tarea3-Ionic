# Tarea 3 - Aplicación Móvil con Ionic

Aplicación móvil desarrollada como parte de la asignatura **Aplicaciones Móviles**.

El proyecto fue creado utilizando **Ionic y Angular** y reúne diferentes herramientas en una misma aplicación, accesibles mediante un menú de navegación.

## Funcionalidades

### Inicio

Página principal con los datos de la estudiante:

- Nombre y apellido
- Matrícula
- Correo electrónico
- Foto 2x2

### Sumadora

Permite ingresar dos números y muestra el resultado de su suma.

### Traductor de números a letras

Convierte números del **1 al 1000** a su representación escrita en español.

La conversión se realiza de manera local dentro de la aplicación, sin utilizar APIs externas.

### Tabla de multiplicar

Permite ingresar un número y genera automáticamente su tabla de multiplicar desde el **1 hasta el 13**.

### Experiencia personal

Sección dedicada a mi experiencia durante el desarrollo del proyecto, acompañada de un video publicado en YouTube.

## Tecnologías utilizadas

- Ionic
- Angular
- TypeScript
- HTML
- SCSS

## Ejecución del proyecto

Para instalar las dependencias:

```bash
npm install
```

Para ejecutar la aplicación:

```bash
ionic serve
```
